# Weekly Meetings

This folder contains records of weekly meetings held throughout the project. These records document key discussions, decisions, challenges, and progress across all development stages.

## Overview

Meetings were conducted on a weekly basis (typically every Tuesday) to coordinate tasks, review progress, and guide the technical direction of the project.

Each week reflects a specific stage of the project lifecycle, including:

* Literature review and problem formulation
* Dataset collection and preparation
* Model selection and baseline development
* Training strategy refinement
* Transformer-based model development
* Final evaluation, documentation, and submission

## Structure

Each file corresponds to a specific project week and follows a consistent format:

* Meeting details (date, attendance)
* Objectives
* Tasks completed
* Discussion points
* Decisions and outcomes
